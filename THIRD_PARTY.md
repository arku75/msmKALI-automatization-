# Upstream projects and attribution

msmKALI orchestrates separately obtained tools. The MIT license in this repository applies to the msmKALI source package covered by that notice; it does not relicense upstream projects, firmware, drivers or documentation.

The original project credits these upstream resources:

- [bkerler / edl](https://github.com/bkerler/edl) — Qualcomm EDL tooling.
- [n00b69 / woa-op7](https://github.com/n00b69/woa-op7) — OnePlus Windows-on-ARM guides and related project resources.
- [Renegade Project](https://renegade-project.tech/) — Windows-on-ARM community resources.
- [Kali NetHunter](https://www.kali.org/docs/nethunter/) — Android/NetHunter documentation and distribution.
- [TWRP](https://twrp.me/) — recovery project.
- [Magisk](https://github.com/topjohnwu/Magisk) — Android root tooling.
- DualBootKernelPatcher — credited by the original toolkit; obtain the appropriate upstream version separately.

Follow each project's own license, documentation and compatibility requirements. This source release contains no upstream firmware, patched manufacturer executables, recovery images, copied WOA guides or personal device data. No affiliation with OnePlus, Qualcomm, Microsoft or the projects listed above is claimed.
